\begin{abstract}
A critical issue of recommender systems is the cold-start problem, which makes giving to new users an accurate personalized product hard and complicated due to scarce interaction history and not enough data to work with. While modern meta-learning methods such as MeLU enable rapid adaptation, they still rely exclusively on categorical data, which limit generalization on unseen items, and furthermore they are based on an assumption of passive and not-well refined support sets that still require dozens of user ratings. In this work, we address both challenges by adding semantic textual representations and Active Learning (AL) into the MeLU baseline on the MovieLens-1M dataset. First of all, we augment item representations with embeddings extracted from movie plots via Sentence-Bert, evaluating model performance across different regimes. Then, to deal with the second obstacle, we introduce a new evaluation protocol by comparing four selection strategies: Random Sampling, Ensemble Uncertainty, Expected Model Change (EMC) and Text Diversity. Experiments show that wise query selection is able to surpass full-history adaptation even with very few interactions (EMC yields the lowest error with k=1 and a MAE of 0.9283). On the other hand, we became aware that high variance items polarized outliers, which destabilized local gradient updates, as shown by Ensemble Uncertainty.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Recommender systems have become a fundamental tool in the digital era, helping users to filter among lots of possibilities and choices. Despite their evolution, these systems still face hard challenges, in particular the so-called “cold-start” scenarios, where it is tough to select which items are better to provide to users given the scarcity of data collected up until that moment. Real possible scenarios could be the release of a new product, the onboarding of new users or platforms with sparse data (Zhang et al., 2025). Gradient-based meta-learning has become a foundational approach for few shot personalization. Specifically, the Meta-Learned User Preference Estimator (MeLU) builds on Model-Agnostic Meta-Learning (MAML) to learn a shared set of starting parameters across users, allowing the model to quickly adapt to a new user’s preferences in just a few local gradient steps (Lee et al., 2019). Despite its effectiveness, standard meta-learning recommendation still faces three main limitations that make it difficult to use:
Shallow Item Representations: standard meta-learning recommenders mostly represent items using discrete IDs and sparse categorical tags (such as genres, actors, or directors). For new, unrated items, these basic features fail to capture indirect semantic similarities with content the user has already rated.
Uniform Initialization and Demographic Dependance: standard MAML begins local adaptation from the exact same global parameters for every user, often relying on explicit demographic data (like age, gender, or occupation). This makes generalization less valuable when users have very different tastes, and makes the approach unusable on platforms that lack demographic profiles.
Passive User Onboarding: existing frameworks treat a user’s initial history as a passively collected list, typically requiring dozens of ratings per user. To avoid asking a new user 30-50 times to rate different items, it is required to actively choose which items to show to them.
In this paper, we address all three challenges by implementing a unified text-aware meta-learning framework built upon dense semantic representations extracted from item descriptions (movie plots).

\section{Method}
\label{sec:method}

\subsection{MeLU}
\label{sec:melu}
MeLU~\cite{lee2019melu} faces the cold-start problem as an optimization-based meta-learning problem, which is built upon MAML. Here each user $i$ corresponds to an individual learning task $\mathcal{T}_i$, and its interaction history is separated into a \emph{support set} $\mathcal{S}_i$ used for local personalization and a \emph{query set} $\mathcal{Q}_i$ which serves as a tool for evaluating generalization and compute global meta-updates.

\paragraph{User Preference Estimator.}
Given a user $i$ with $P$ categorical attributes and an item $j$ with $Q$ categorical attributes, MeLU first maps each one-hot feature vector $c_{ip}$ and $c_{jq}$ into dense $d_e$-dimensional embeddings by concatenating learned embedding matrices $E_{ip}$ and $E_{jq}$ into user and item representations:
\begin{equation}
    U_i = [E_{i1}c_{i1}; \dots; E_{iP}c_{iP}]^\top, \qquad
    I_j = [E_{j1}c_{j1}; \dots; E_{jQ}c_{jQ}]^\top.
\end{equation}
We denote the set of all user and item embedding parameters as $\theta_1$. The concatenated representation $x_0 = [U_i; I_j]$ is fed into an $N$-layer fully-connected decision-making network followed by a linear output layer to predict the explicit rating $\hat{y}_{ij}$:
\begin{equation}
    x_n = \mathrm{ReLU}(W_n^\top x_{n-1} + b_n), \qquad
    \hat{y}_{ij} = W_o^\top x_N + b_o,
\end{equation}
for $n \in \{1, \dots, N\}$. We denote the decision-making and output layer parameters as $\theta_2 = \{W_1, b_1, \dots, W_N, b_N, W_o, b_o\}$.

\paragraph{Bi-Level Meta-Optimization.}
In order to adapt a user’s specific tastes, the strategy MeLU exploits to accomplish its goal and to avoid overfitting on scarce interactions is to decouple parameter updates into a local inner loop and a global outer one. During the \emph{local update}, stable entity representations are preserved by keeping the embedding parameters $\theta_1$ frozen, while only the decision-making parameters $\theta_2$ are adapted on the user's support set $\mathcal{S}_i$ by minimizing the Mean Squared Error (MSE):
\begin{equation}
    \mathcal{L}_{\mathcal{S}_i}(\theta_1, \theta_2) = \frac{1}{|\mathcal{S}_i|} \sum_{j \in \mathcal{S}_i} (y_{ij} - \hat{y}_{ij})^2,
\end{equation}
yielding user-specific parameters $\theta_2^{(i)}$ after one or more gradient steps with inner learning rate $\alpha$:
\begin{equation}
    \theta_2^{(i)} \leftarrow \theta_2 - \alpha \nabla_{\theta_2} \mathcal{L}_{\mathcal{S}_i}(\theta_1, \theta_2).
\end{equation}
Instead, during the \emph{global update}, the meta-learner evaluates the adapted parameters $\theta_2^{(i)}$ on the query set $\mathcal{Q}_i$ across a mini-batch of users $\mathcal{B}$, updating both $\theta_1$ and $\theta_2$ with outer learning rate $\beta$:
\begin{equation}
    \theta_1 \leftarrow \theta_1 - \beta \sum_{i \in \mathcal{B}} \nabla_{\theta_1} \mathcal{L}_{\mathcal{Q}_i}(\theta_1, \theta_2^{(i)}), \qquad
    \theta_2 \leftarrow \theta_2 - \beta \sum_{i \in \mathcal{B}} \nabla_{\theta_2} \mathcal{L}_{\mathcal{Q}_i}(\theta_1, \theta_2^{(i)}).
\end{equation}
At inference time, a cold user's preferences are estimated by adapting $\theta_2$ on their available support interactions $\mathcal{S}_i$ and predicting ratings for unseen items. We highlight that the original MeLU framework also implemented a heuristic evidence candidate selection rule based on global gradient norms and item popularity, but it assumes passive support sets during standard evaluation too.~\cite{lee2019melu}—a limitation we directly address in Section~\ref{sec:active_learning}.
